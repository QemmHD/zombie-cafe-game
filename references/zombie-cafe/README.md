# Reference set — *Zombie Cafe* (Beeline, 2011)

These folders mirror the reference categories analysed in
`/docs/reference-analysis.md`. The actual screenshots are **copyrighted** and are
**git-ignored** (`references/.gitignore`) — drop your local captures into the
matching folder to view them while working; they will never be committed.

| Folder | What goes here (described in reference-analysis.md §) |
|---|---|
| `home-cafe/` | the cutaway café hub w/ exterior, grimy room, HUD, side icons (§1) |
| `tutorial/` | giant undead-chef portrait + chalkboard dialogue + arrows (§2) |
| `build-store/` | bottom category tray w/ thumbnails, prices, locked items (§3) |
| `placement/` | ghost object + green/red tiles + cost/XP panel (§4) |
| `expansion/` | green new-footprint outline + "expands to NxM" (§5) |
| `cookbook/` | full paper recipe book, slots, dish card, variant tokens (§6) |
| `raid-map/` | iso neighbourhood of café buildings w/ labels/timers (§7) |
| `raid-battle/` | enemy-café combat, health bars, action panel, pets, loot (§8) |
| `fridge-loot/` | open fridge w/ stolen dish, Serve/Unlock (§9) |
| `meat-locker/` | cold-storage room, hanging hooks, capacity (§10) |
| `zombiepedia/` | collection scrapbook, silhouettes, unlock reqs (§11) |
| `review-board/` | task board, pinned note, progress, bonus star (§12) |
| `level-up/` | framed board + pinned unlocked-dish card (§13) |
| `infection/` | in-world INFECT button + thought bubble + transform (§14) |
| `options/` | brick-wall settings, sliders, themed slabs (§15) |

Originality rule: capture **structure / density / composition / interaction feel**.
Never copy exact art, sprites, logos, UI graphics, dialogue, recipe names or brand.
